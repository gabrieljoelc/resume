# resume

Gabriel Chaney's career pipeline. Evidence of work goes in, Claude shapes it into a public-safe profile, and the profile fans out to LinkedIn and gabrielchaney.com.

```
data/ ──/refresh──▶ profile.yaml ──┬──▶ linkedin.md ──paste──▶ LinkedIn
                                   └──CI──▶ site/ ──▶ Vercel (HTML + PDF)
```

- `data/`: dated evidence entries, one per piece of work, captured with `/log`
- `profile.yaml`: public-safe profile in [JSON Resume](https://jsonresume.org/schema) format, updated with `/refresh`
- `linkedin.md`: paste-ready LinkedIn copy, generated by `/refresh`
- `site/`: renders `profile.yaml` to HTML and PDF, deployed to Vercel

Rules for Claude live in [CLAUDE.md](CLAUDE.md).
